- Adding and removing array elements

## Daily Coding Challenges

The `daily-challenges/` folder contains five JavaScript exercises.

| File | Challenge |

| `day-1-fizzbuzz.js` | Print FizzBuzz results for numbers 1–20 |
| `day-2-reverse-string.js` | Reverse a string |
| `day-3-largest-number.js` | Find the largest number in an array |

| `day-5-palindrome-checker.js` | Check whether a word or phrase is a palindrome |

## How to Run the Project

1. Open `index.html` in a web browser.
2. Open the browser's Developer Tools.
3. Select the **Console** tab.
4. View the JavaScript exercise results.

The project can also be opened in Visual Studio Code. The daily challenge files can be run individually using a JavaScript runtime such as Node.js, if installed.
